# Resolve application directories by platform convention

SpaceTerm exposes one semantic `AppDirectories` value while resolving it through XDG on Linux and macOS and Windows Known Folder APIs on Windows. XDG uses only non-empty absolute overrides and otherwise derives persistent roots from `HOME`; Windows uses the stable `sadiksaifi/spaceterm` namespace beneath Roaming AppData for portable configuration and Local AppData for machine-local data, state, logs, and caches. Resolution never creates directories, secure storage creates them only immediately before writing, and credentials remain owned by native credential facilities rather than these paths.

Filesystem runtime directories remain optional because they cannot represent every platform's IPC guarantees. Unix adapters may use an XDG runtime directory or a private OS-temporary fallback, while a Windows adapter should use ACL-restricted named pipes or other native primitives for IPC and reserve its private temporary runtime directory for file-backed artifacts. Packaged applications must supply container-resolved roots without changing the semantic interface.
