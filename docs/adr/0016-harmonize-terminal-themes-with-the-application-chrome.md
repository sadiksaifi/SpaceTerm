# Harmonize Terminal Themes with the Application Chrome

The Application Chrome stays SpaceTerm's, and Terminal Themes adapt to it: Theme Harmonization moves a theme's background into the band SpaceTerm's own Panes rest in, keeping its hue and its text contrast. It runs at resolution rather than at install, so installed themes keep their authored colors and retuning the band needs no reinstall. A background the person overrides is used as authored.
