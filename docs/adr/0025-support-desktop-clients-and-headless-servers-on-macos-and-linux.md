# Support desktop clients and headless SpaceTerm Core on macOS and Linux

The production [client and Core architecture](https://github.com/sadiksaifi/SpaceTerm/issues/520) supports desktop SpaceTerm Clients and headless SpaceTerm Core installations on macOS and Linux. The shared protocol also accommodates iOS, Android, and Windows clients. Implementation of mobile and Windows clients is deferred, and the agreed production behavior applies to those clients too.
