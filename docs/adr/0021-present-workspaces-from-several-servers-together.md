# Present Workspaces from several servers together

One SpaceTerm Client connects to several SpaceTerm Servers simultaneously and groups their Workspaces by machine in the sidebar. This preserves access to work on several machines in one Operating-System Window. Each Workspace remains owned by its server.

The sidebar presents that client's [Workspace Attachments](0032-keep-workspace-attachments-specific-to-each-client.md). Connecting to a server makes its own Workspaces available; it does not expose Workspaces on other servers that a client on that machine happens to use.

Workspace order keeps each machine's Workspaces together: this computer's first, then SSH machines by SSH Destination, then direct network servers by their reported names. An SSH route and a direct route to the same computer have separate headings because they carry separate authority. Each remote heading identifies its connection method. A heading names each machine once more than one machine is presented, or while a remote server is presented or a Saved Connection keeps trying to connect, and shows that server's connection state when it is not connected. A presented server with no attached Workspaces keeps its heading, and so does a Saved Connection with reconnect intent before it connects, which offers Connect while it waits for the person. Every such heading offers Disconnect. Reordering stays within a machine's group.
