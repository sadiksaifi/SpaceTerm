# Support desktop clients and headless servers on macOS and Linux

The planned production [server architecture](https://github.com/sadiksaifi/SpaceTerm/issues/520) supports desktop SpaceTerm Clients and headless SpaceTerm Servers on macOS and Linux. The shared protocol also accommodates iOS, Android, and Windows clients. Implementation of mobile and Windows clients is deferred, and the agreed production behavior applies to those clients too.
