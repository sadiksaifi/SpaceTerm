SpaceTerm credential-tool corresponding source and replacement libraries

This archive dynamically links systemd-creds to private LGPL libraries. It does
not replace the host's systemd, systemctl, C library, or service manager.

share/sources/systemd.tar.gz is the exact systemd commit recorded in recipe.json.
The other share/sources/*.tar files contain the complete Ubuntu source-package
inputs, including the .dsc file, upstream archives, and Debian/Ubuntu patches.
source-components.json records the SHA-256 of each input. packages.tsv records
the exact binary and source-package versions in the compiler image. Every
shipped library has its own copyright/license record under share/licenses.

The builder recipe is Jammy.Dockerfile. Build it with Docker and record the
resulting image SHA-256. Run build.py with python3 -I inside that image as an
unprivileged user, from a separate /driver directory. Pass the source archive,
recipe.json, a new empty scratch parent, and new output and receipt paths as
arguments. The recipe compiles only the systemd-creds target and its required
libsystemd-shared library. Meson options, compiler version, image identity,
private-library binary digests, and source digests are in the build receipt.
The exact effective Meson options are in meson-options.json.

For a distro dependency, unpack its .tar into a new source-input directory and
run dpkg-source -x on its .dsc file from a separate working directory. That
reconstructs the source and applies the included patches. The source package's
debian/rules and build dependencies describe Ubuntu's library build. Rebuild a
modified library for x86_64 glibc 2.35 or earlier and retain its SONAME and ABI.
The shipped binaries were obtained from Ubuntu's signed Jammy archive, then
copied as regular files and transformed with patchelf --set-rpath '$ORIGIN'.
The tool's RUNPATH is '$ORIGIN/../../lib/credential-tools'. The recorded
0001-spaceterm-private-credential-policy.patch is applied before compilation.
It is shipped under share/sources/build-material with its exact recipe digest.
The patch restricts the CLI to anonymous-stream Host/HostAndTpm2 enrollment and
startup decrypt, verifies dumpable zero, requires mlockall for secret-bearing
execution, disables plaintext stdio buffering, and preserves upstream wiping.
Startup decrypt opens existing host-key storage without provisioning or repair.
It rejects unsupported ciphertext recipes before accessing native keys.
The build receipt hashes the patched and transformed binaries. Every build
gets a new build identity and resets all native runtime evidence to unrun.
That identity is recorded in authenticated build-info.json and the sibling
JSON receipt. Packaging binds both to the exact evidence recorded in the pin.

A modified LGPL library may replace its matching private shared library in a
local test copy. No application relinking objects are needed for this dynamic
linking arrangement. The tool remains dynamically linked; the build material
also permits rebuilding and relinking the tool. Preserve the library licenses
and the complete corresponding source when redistributing modified copies.

Production admission is separate from copyright permissions. A modified
installation requires a new authenticated, protected native installation.
Do not change an approved generation in place. Replacement cannot bypass
native code authentication, credential policy, or OS authorization.

The private OpenSSL configuration admits only the default provider built into
libcrypto.so.3. The native adapter must bind OPENSSL_CONF to the authenticated
share/spaceterm-server/credential-tools/openssl.cnf and OPENSSL_MODULES to the
private library directory. It must not inherit account-selected configuration,
providers, loader variables, or TPM configuration. A compiler-container version
check is not Host-key, TPM, kernel 5.15, systemd 249, or custody evidence.
