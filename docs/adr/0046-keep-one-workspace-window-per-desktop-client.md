# Keep one Workspace Window per desktop client

Each desktop SpaceTerm Client presents its Workspace Attachments in one main Workspace Window, preserving SpaceTerm's single-window design. The client application remains the scope for [Pane control](0022-give-one-client-control-of-each-pane.md) and [Client View State](0041-keep-each-clients-view-independent.md). The Settings Window retains its separate presentation under [ADR 0005](0005-present-settings-in-a-separate-operating-system-window.md).

[ADR 0023](0023-allow-confirmed-tab-closure-across-clients.md) defines final-close consequences, while [ADR 0032](0032-keep-workspace-attachments-specific-to-each-client.md) defines explicit Detach and its valid empty attachment view.
