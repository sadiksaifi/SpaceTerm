# Carry paired connections over QUIC

Paired connections run over QUIC, the only paired transport. WSS, its TCP listener and its code are deleted, with no fallback. On a lossy network the tail of a paired keystroke came from TCP: Linux recovers a lost lone packet only after its 200 ms minimum retransmission timeout, and every later frame waits behind it on the one byte stream. QUIC recovers after one probe timeout derived from the measured round trip, and a lost packet stalls only its own stream. At 2% loss and 25 ms added delay on the server's side, QUIC cut keystroke-to-echo p99 from 257 ms to 82 ms, the p99 of a pushed page of output from 283 ms to 83 ms, and the p99 of a 200-row Scrollback page from 290 ms to 114 ms. On a clean wired LAN a keystroke costs the same on both: 2.0 ms over WSS and 2.1 ms over QUIC at p50, each n = 300.

SpaceTerm drives noq-proto, the QUIC state machine that n0's iroh runs on, from each connection's own I/O thread. noq-proto does no I/O and needs no runtime, so a frame crosses no extra thread on the client, and the server's one UDP socket is read by a listener thread that hands each datagram to its connection's thread. iroh itself was measured and rejected: its relay client, DNS resolver and network monitor are not optional, link Apple's Security, SystemConfiguration and CoreFoundation frameworks, which the macOS server cannot link when it is cross-compiled on Linux, and doubled the server binary. Its runtime thread added about 0.9 ms per keystroke on the LAN. noq-proto adds 31 crates and about 1 MB to the server and links no framework.

Trust is unchanged under [ADR 0027](0027-trust-paired-clients-equally.md) and [ADR 0028](0028-use-spaceterm-protocol-over-every-client-connection.md). TLS 1.3 inside QUIC presents the same pinned server certificate, and the pairing exchange then verifies the server's proof key and the device's proof. The client also presents a self-signed certificate of its device key, and the server requires that key to be the enrolled key of the device that proves itself, so a proof cannot travel on another device's connection. Endpoints are `quic://HOST:PORT`; the server listens on UDP at its exposure's address and port, 9231 by default.

Frames of one priority level arrive in the order they were offered. L0 is the bidirectional stream the server opens for pairing and admission; the server writes L1 and L2 on unidirectional streams of their own, so bulk transfers and lost frame packets never hold up L0. The client writes every level on L0, so a cancellation or an edit acknowledgement never overtakes its request. On close the server finishes all three streams, and the client holds the server's goodbye until L1 and L2 end, so a goodbye never overtakes frames in flight. Across server levels there is no other order, as on WSS's priority queue.

Terminal traffic is a few packets at a time, so the configuration favors recovery over economy. Each side asks the other to acknowledge every packet at once, which keeps acknowledgement delay out of the probe timeout. The congestion window never falls below ten packets, the usual initial window, because Cubic grows only while its window limits sending, so random loss alone would ratchet it down to two packets and a screen of output would wait a round trip. BBR paced this traffic far too slowly. Keepalives every 10 seconds hold the UDP flow open through routers.

A client whose network changes moves to a new UDP socket, and QUIC validates the new path without a second handshake or admission, so the client keeps Pane control. A send that fails because the local address left triggers the move. The physical switch between Wi-Fi and Ethernet still needs a test on the owner's machines.

Some networks block UDP. SpaceTerm has no TCP fallback under the rule against dual transports; such a network needs a VPN or tailnet route, as an unreachable WSS port did. A later hosted relay fits without changing this decision: it forwards encrypted QUIC datagrams between the two devices, as iroh's relays and TURN do, and never terminates TLS. noq-proto takes datagrams from any source, so the relay is a second socket path inside the carrier, and the pinned certificates still authenticate both ends.

This decision amends the transport in ADR 0027, ADR 0028, [ADR 0029](0029-enroll-remote-servers-through-add-server.md), [ADR 0030](0030-start-servers-at-boot-independently-of-clients.md), [ADR 0034](0034-confirm-server-update-restarts-and-explain-incompatibility.md), [ADR 0038](0038-unpair-devices-without-blocking-local-connection-removal.md), [ADR 0039](0039-scope-settings-to-the-client-or-selected-server.md), [ADR 0045](0045-freeze-terminal-screens-while-reconnecting.md) and [ADR 0050](0050-push-terminal-presentation-over-one-multiplexed-connection.md). Messages, flow control and admission stay as ADR 0050 defines them.
