# Scope Settings to the client or selected Machine

Client Settings belong to the device; Machine Settings belong to one SpaceTerm Core. Machines and Git share a searchable Machine picker listing This Mac or This Computer, then saved paired Machines, and Add Machine. Selection persists outside the Settings Document and falls back to This Mac or This Computer when removed. [ADR 0029](0029-enroll-remote-servers-through-add-server.md) owns Add Machine.

The selected Machine card presents status, version and Terminal Sessions. Every connected Machine card offers Status, Restart and Update, and the card for This Mac or This Computer also offers Stop. A remote card reads Status through Check Now and takes each change over the service lane under [ADR 0057](0057-administer-servers-over-the-service-lane.md), with the CLI's previews, confirmations and operation ledger. Start and Stop stay on the Machine itself, because a stopped SpaceTerm Core accepts no connection, and a remote card says so. Only This Mac or This Computer offers automatic-start policy, Install, Uninstall, Network Access, invitations, device administration and End All Sessions. Remote cards also retain connection facts, Connect or Try Again, Disconnect and Remove Machine. Their saved address is read-only; using a different address requires adding that Machine again. End All Sessions follows [ADR 0048](0048-end-all-sessions-from-the-selected-servers-settings.md).

Opening, selecting, rendering or searching Settings creates no remote connection. A remote card opens a service lane connection only when the person chooses Check Now, Restart or Update. Connected observations use the existing [QUIC connection](0052-carry-paired-connections-over-quic.md); inactive Machines show last-known facts and how to reconnect. Each new connection reads SpaceTerm Core's own facts again, so a Machine that restarted or updated shows its current version. Unreachable network policy and device lists remain distinct from confirmed Off or an empty list. Displayed facts grant no mutation authority. Connection state follows [ADR 0045](0045-freeze-terminal-screens-while-reconnecting.md).

Interface, Font, Themes, Keybindings, clipboard, Git presentation, client updates and the Command Line Tool remain client-owned. The Command Line Tool row ignores the picker; [ADR 0054](0054-use-one-headless-executable.md) owns its launcher. [Clipboard authority](0013-order-terminal-clipboard-access-by-session-focus.md), [Pane control](0022-give-one-client-control-of-each-pane.md) and [client-local GitHub CLI lookups](0018-read-repository-status-by-running-git-and-the-github-cli.md) retain their boundaries.

Git discovery and writes use the owning Machine's tools and filesystem. "Git on <Machine>" owns New Worktree Location; validation checks that Machine's filesystem and effective directory permissions. Concurrent edits reload the authoritative value and explain the change. Edits on an offline Machine remain unavailable. [System Permissions](0061-own-system-permissions-in-the-server-package.md) belong to This Mac or This Computer. The Privacy section presents them with [Permission Setup](0014-guide-permission-setup-on-system-settings.md), and no Machine card offers them.

This Mac or This Computer offers no removal. Remote removal and revocation follow [ADR 0038](0038-unpair-devices-without-blocking-local-connection-removal.md). Import, export and reset affect Client Settings and installed Terminal Themes only. Connections, authorization, operations, attachments, views, Workspace organization, Machine Settings and deliberate Stop remain outside the Settings Document.
