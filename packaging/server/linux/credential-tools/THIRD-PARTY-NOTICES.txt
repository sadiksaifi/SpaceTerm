Individual source files identify exceptions. UPSTREAM-LICENSE-NOTES.txt describes them.

Every released package must include the exact systemd source archive, all patches,
complete build options, compiler and build-image identities, and build material.
Each bundled dependency must include its own exact source archive and license.
The private shared-library arrangement must permit local replacement and rebuilding
of LGPL libraries. Native credential delivery to modified code still requires an
explicit authenticated installation. It does not grant automatic approval to a
modified library or remove the local-use rights of the license.

The downstream credential-policy patch is by the SpaceTerm contributors and is
licensed under LGPL-2.1-or-later. Its exact source and recipe digest accompany the
upstream source under share/sources/build-material. Build completion and license
permissions do not establish native runtime approval.
