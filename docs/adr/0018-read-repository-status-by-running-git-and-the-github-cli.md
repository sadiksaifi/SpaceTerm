# Read Repository Status by running git and the GitHub CLI

Repository Status runs the person's own git on the owning SpaceTerm Server and parses one porcelain format, so results follow that machine's git configuration and Worktree layout. Clients read those facts through SpaceTerm Protocol over their existing connection. Pull Requests come only from the client-local GitHub CLI, which owns GitHub credentials as OpenSSH owns SSH credentials, and lookups happen only when a branch, upstream, or window activation changes. We accept that clean filters and Git's built-in fsmonitor daemon may run under the person's configuration, while hooks and hook-program fsmonitors never do.
