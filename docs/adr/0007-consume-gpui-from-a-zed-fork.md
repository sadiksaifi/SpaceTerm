# Consume GPUI from a Zed fork

SpaceTerm consumes GPUI and its platform crates from a SpaceTerm fork of Zed pinned by a dated Git
tag. The published GPUI crate is stale. Vendoring Zed into this repository or adding a Git
submodule would make updates and ownership harder to track. The patches live as commits on the
fork's `spaceterm` branch. Each month, maintainers rebase that branch onto upstream Zed, validate
the fork, create a new dated tag, and bump SpaceTerm to that tag.
SpaceTerm's Rust toolchain matches the fork's on each bump, because both build the same
dependencies. Compiler issues in Zed's dependencies are fixed upstream, not patched here.

An untracked Cargo configuration generated by `mise run gpui:local:on` selects a local fork checkout
for development. `mise run gpui:local:off` restores the pinned tag. Patches suitable for upstream
should be offered to Zed.
